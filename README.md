# MetaClean 🧹

### Remove AI Metadata. Protect Your Privacy.

MetaClean is a privacy-focused web application designed to help remove hidden metadata and AI-related information from images and videos before sharing them.

🔒 **Privacy First:** Files are processed directly on your device wherever supported. No uploads or file storage on external servers.

## ✨ Features

- 🖼️ **Image Metadata Removal** — Clean supported image metadata.
- 🎥 **Video Metadata Removal** — Process supported video formats.
- 🔍 **Metadata Preview** — Inspect available metadata before and after processing.
- 📦 **Batch Processing** — Process multiple files where supported.
- ✅ **Verification** — Check the output files after processing.
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile screens.
- 🔐 **Local Processing** — Designed to keep your files on your device.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/AyushGorlawar/MetaClean
```

Navigate to the project directory:

```bash
cd MetaClean
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🔒 Privacy

MetaClean is designed with a privacy-first approach. Supported processing runs locally in your browser, helping you avoid uploading personal files to a server.

**Important:** Removing metadata does not guarantee removal of every AI-related indicator. Some information may be embedded in image pixels, video frames, watermarks, or external provenance systems. Always verify the processed output.

## 🎯 Project Goal

Make it easier for people to inspect and clean image and video metadata before sharing files online.
